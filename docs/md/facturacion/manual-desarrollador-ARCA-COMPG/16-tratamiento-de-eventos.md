##### Tratamiento de eventos 

El tratamiento de eventos en todos los servicios se realizará de la siguiente manera: 
```xml
<Events>
  <Evt>
    <Code>
      **int**
    </Code>
    <Msg>
      **string**
    </Msg>
  </Evt>
  <Evt>
    <Code>
      **int**
    </Code>
    <Msg>
      **string**
    </Msg>
  </Evt>
</Events>
```
 Dónde: 

,**Campo Detalle Obligatorio** Events Array de objeto. Evt Información correspondiente al mensaje 

###### N 

Code Código de evento S Msg Detalla el evento que se desea comunicar S
