##### Método para consultar las actividades (FEParamGetActividades) 

Esta operación permite consultar los códigos de actividades, sus descripciones y el orden (si es actividad primaria, secundaria, etc) **Dirección URL (Homologación)** Este servicio se llama desde: https://wswhomo.afip.gov.ar/wsfev1/service.asmx?op= FEParamGetActividades
