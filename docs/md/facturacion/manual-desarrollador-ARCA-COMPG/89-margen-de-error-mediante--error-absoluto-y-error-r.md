##### Margen de error mediante (Error Absoluto y Error Relativo) 

 Error Absoluto eabs : Es la diferencia entre el valor medido (calculado) y el valor real Error Relativo erel : Es el cociente entre el valor error absoluto y el valor real. En ambos casos se tomará el valor absoluto, es decir el signo resultante de la operación no se considerará. El criterio de redondeo que utilizamos en este servicio es Round Half Even.
